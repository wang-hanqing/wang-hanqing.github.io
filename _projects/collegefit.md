CollegeFit is a Java course project motivated by my work with newcomer youth. It aims to make college exploration more approachable when students have incomplete information about academic requirements, costs or preferences.

The design uses U.S. Department of Education College Scorecard data to organize program evidence, academic context, financial information and social preferences. It distinguishes missing information from known non-matches and avoids presenting admission predictions.

The current scope is a Java MVP in development, with a possible future browser-based version.
