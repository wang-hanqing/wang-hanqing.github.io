This team course project explored how a physical drawing interaction could be connected to a cloud-based machine learning pipeline.

The prototype used an M5Stack Core2 device, MQTT and AWS IoT Core, with four mood categories. The project explored data collection, model performance and end-to-end response latency.

This is an experimental prototype, not a clinical mood assessment tool.
